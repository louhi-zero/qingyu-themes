# 轻语记账 · 主题仓库

轻语记账「主题商城」的官方主题目录（仓库即 CMS）。

- `themes.json`：主题目录索引
- `themes/<id>/manifest.json`：主题清单（palette/壁纸/图标）
- `themes/<id>/wall.jpg`：主题壁纸；`tab/ disc/ cat/`：底部菜单 / 发现页 / 账目分类图标（主题色线稿）

三平台镜像：GitHub `louhi-zero/qingyu-themes` · Gitee `Roxie-zero/qingyu-themes` · GitCode `Roxie-sama/qingyu-themes`
